=====================================================
   echanta.dz  —  متجر الحقائب النسائية (النسخة الكاملة)
=====================================================

المحتويات
- واجهة الزبون (فرنسي/عربي) بدون تسجيل دخول: الرابط  /
- لوحة الأدمين بكلمة مرور: الرابط  /admin
- ألوان المنتج من الصور: في المنتج الواحد أضف عدة صور، كل صورة = لون.

------------------------------------------------
أولا: التشغيل على جهازك (ويندوز / ماك / لينكس)
------------------------------------------------
1) ثبّت Node.js (الإصدار LTS) من:  https://nodejs.org
2) فك ضغط الملف.
3) ويندوز: انقر مرتين على  start.bat
   ماك/لينكس: افتح الطرفية داخل المجلد واكتب:  ./start.sh
   (أو يدويا:  npm install  ثم  node server.js )
4) افتح المتصفح:
     المتجر:   http://localhost:3000
     الأدمين:  http://localhost:3000/admin

بيانات الدخول الأولى:
     اسم المستخدم:  admin
     كلمة المرور:   admin123
غيّرها فورا من  الإعدادات ← تغيير بيانات الدخول.

------------------------------------------------
ثانيا: طريقة استعمال لوحة الأدمين
------------------------------------------------
• المنتجات ← «منتج جديد»:
    - اكتب الاسم والسعر (والسعر القديم إن أردت إظهار تخفيض) والوصف.
    - اضغط «إضافة صور» واختر عدة صور (كل صورة لون مختلف من نفس الحقيبة).
    - يُقترح اسم اللون ولونه تلقائيا من الصورة.
    - لاختيار اللون بنفسك: اضغط على الصورة أو زر «التقاط اللون من الصورة»
      ثم انقر على أي نقطة في الصورة. يمكنك أيضا تعديل الاسم أو اللون يدويا.
    - الأسهم ▲▼ لترتيب الصور، والأولى هي الصورة الرئيسية.
    - «ظاهر في المتجر» لإخفاء/إظهار المنتج، و«متوفر في المخزون» لإيقاف الطلب عند نفاد الكمية.
• أسعار التوصيل:
    - جدول بالـ 58 ولاية: سعر التوصيل إلى المنزل وإلى مكتب التوصيل لكل ولاية.
    - اترك الخانة فارغة = غير متوفر في تلك الولاية، و 0 = توصيل مجاني.
    - زر «تطبيق على الكل» لتوحيد السعر ثم عدّل الولايات المختلفة.
    - الأسعار الموجودة افتراضيا تقريبية، عدّلها حسب شركة التوصيل لديك.
• الطلبات:
    - تصلك كل طلبية بالاسم واللقب والهاتف والولاية ونوع التوصيل واللون المختار.
    - انقر على الطلب لتغيير حالته (جديد/مؤكد/تم الشحن/تم التسليم/ملغى) أو حذفه.
    - زر «تصدير CSV» لفتح الطلبات في Excel.
• الإعدادات: رقم الهاتف وواتساب وإنستغرام وفيسبوك + تغيير كلمة المرور.

------------------------------------------------
ثالثا: النشر على الإنترنت باسم echanta.dz
------------------------------------------------
الموقع يعمل بـ Node.js، لذلك تحتاج استضافة تدعم Node.js (أو VPS):
1) ارفع كل الملفات إلى السيرفر (بدون مجلد node_modules).
2) نفّذ:  npm install --omit=dev
3) شغّل:  PORT=3000 node server.js    (يفضل مع pm2 ليبقى يعمل دائما:  npm i -g pm2 && pm2 start server.js --name echanta)
4) اربط الدومين echanta.dz بالسيرفر (سجل A في DNS) وضع Nginx أو Caddy أمام التطبيق
   مع شهادة HTTPS (مثال Caddy:  echanta.dz { reverse_proxy localhost:3000 } ).
5) يمكن تحديد كلمة مرور الأدمين عند أول تشغيل:  ADMIN_PASSWORD=كلمتك node server.js

ملاحظات مهمة
- كل البيانات في مجلد  data/db.json  والصور في  uploads/  ← خذ منهما نسخة احتياطية باستمرار.
- المتجر يعمل بدون أي قاعدة بيانات خارجية، ولا حاجة لإعداد MySQL.
- الدفع عند الاستلام، والسعر يُحسب في السيرفر (لا يمكن للزبون التلاعب به).
